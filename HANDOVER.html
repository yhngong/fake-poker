1. Executive Summary

Fake Poker is a responsive Texas Hold'em web game built with zero external runtime dependencies (vanilla HTML5, CSS3, ES6 JavaScript). The project supports dual execution:

  • 100% Offline Single-Player: Runs fully client-side against 3 adaptive AI opponents (Bob, Alice, and Charlie) with Web Audio sound effects. Ideal for GitHub Pages.
  • Online Multiplayer: Powered by Cloudflare Workers and Durable Objects (PokerRoom). Supports real-time authoritative Texas Hold'em across rooms (?room=<code>) with private hole cards, live chat, dealer bribes, and bot fill-in for empty seats.

3. Core Systems & Architecture

🃏 Authoritative Hand Evaluator

Evaluates 7-card combinations down to best 5-card holding with full category and tie-breaker sorting:

  • High Card up to Royal Flush
  • Ace-low Wheel Straight (A-2-3-4-5) & Broadway (10-J-Q-K-A)
  • Handles incomplete hands safely during pre-flop and flop
🌐 Cloudflare Durable Objects

Each room code (e.g. ?room=table-777) binds to an isolated PokerRoom instance:

  • Authoritative deck, blinds, turns, split pots, and timeouts
  • Private cards: Each client receives only their own hole cards
  • Empty seats automatically staffed by bots
🤫 Dealer Bribe System

Interactive modal and chat commands (##deal, ##peek):

  • 👁️ Peek Cards ($250): Reveals opponents' cards face-up.
  • 🤝 Specific Card ($500): Picker forces exact card on board or river.
  • ✨ Best Card ($750): Algorithmic solver deals optimal card.
👤 Persona & Avatars

Consistent player bust avatar (👤) with head accessories:

  • Bob: Fedora 🎩
  • Alice: Crown 👑
  • Charlie: Sunglasses 🕶️
  • Player / Human: Cap 🧢 (customizable in lobby)

4. WebSocket Protocol Specification

Bidirectional JSON messaging over /ws?room=<room_code>:

Client ➔ Server:

// 1. Join Room
{ "action": "join", "name": "Alex", "accessory": "👑" }

// 2. Player Betting Action
{ "action": "player_action", "type": "fold" | "check" | "call" | "raise", "amount": 80 }

// 3. Dealer Bribes
{ "action": "bribe", "bribeType": "peek" }
{ "action": "bribe", "bribeType": "best_card" }
{ "action": "bribe", "bribeType": "specific_card", "card": { "rank": "A", "suit": "♠" } }

// 4. Chat & Deal Next Hand
{ "action": "chat", "text": "Nice bluff!" }
{ "action": "start_hand" }

Server ➔ Client:

// 1. Welcome (assigns seat index 0..3)
{ "type": "welcome", "seatIdx": 0, "sessionId": "session_...", "name": "Alex", "accessory": "👑", "chips": 1000 }

// 2. Authoritative Room State Broadcast
{
  "type": "room_state",
  "phase": "PRE-FLOP" | "FLOP" | "TURN" | "RIVER" | "SHOWDOWN" | "IDLE",
  "pot": 60,
  "currentBet": 20,
  "dealerIdx": 1,
  "currentTurnIdx": 0,
  "communityCards": [{ "suit": "♠", "color": "black", "rank": "A", "val": 14 }],
  "seats": [
    { "id": 0, "name": "Alex", "accessory": "👑", "isHuman": true, "chips": 980, "currentBet": 20, "folded": false, "allIn": false, "holeCards": [{ "rank": "K", "suit": "♠", ... }] },
    { "id": 1, "name": "Bob", "accessory": "🎩", "isHuman": false, "chips": 1000, "currentBet": 0, "folded": false, "allIn": false, "holeCards": [{ "hidden": true }] }
  ],
  "yourSeatIdx": 0
}

// 3. Notifications & Bribe Confirmations
{ "type": "bribe_success", "bribeType": "peek" | "best_card" | "specific_card", "card": { ... } }
{ "type": "chat", "sender": "Alice", "text": "Talk is cheap, show some chips!", "className": "chat-bot" }
{ "type": "log", "text": "🃏 Hand #4 started!", "logType": "system" }

5. Critical Gotchas & Bugfixes Resolved

Issue Root Cause Resolution
Asset Too Large (86.1 MiB) [assets] directory = "." made Wrangler scan node_modules/workerd binary. Created .assetsignore and mapped static assets cleanly to public/.
Live-Reload Disconnect Loop Miniflare wrote to .wrangler/state/v3/.../metadata.sqlite-shm, which triggered Wrangler's root asset watcher, rebooting workerd and dropping all WebSockets. Isolated static assets into public/ folder, separating them from .wrangler/.
Pre-Flop Bribe TypeError findBestNextCard called evaluate7 with only 3 cards during pre-flop; incomplete hand had undefined tieBreakers, crashing compare. Padded candidate board to 5 cards with remaining deck candidates; made HandEvaluator.compare null-safe.
Chrome DevTools 404 Chrome DevTools automatically probes /.well-known/appspecific/com.chrome.devtools.json. Added silent HTTP 204 handler in Worker.
Missing Favicon 404 Browsers requested /favicon.ico causing 404 logs. Added SVG spade icon (♠) response on /favicon.ico and in index.html.

6. Developer Quickstart & Run Commands

Local Development (Unified Frontend + Backend):

# 1. Ensure nvm/node is in your shell
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"

# 2. Run local Cloudflare Worker & WebSockets
npm run dev

# 3. Open in browser:
# http://localhost:8787 (serves both UI and ws://localhost:8787/ws)

Production Cloudflare Worker Deployment:

# Login to Cloudflare account
npx wrangler login

# Deploy Durable Object Worker
npm run deploy

Standalone Static Frontend (GitHub Pages or Python):

# Run local static server
python3 -m http.server 8000
# Visit http://localhost:8000 (enter deployed Worker wss:// URL in Online dialog)
